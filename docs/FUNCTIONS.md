# Artifact guide

This repository is the binary/provenance companion to the logo/gradient
scroller source. The corrected image is the root PRG; the supplied image stays
under original/.

The matching source snapshot contains the same entry contract: CBM load address
$0801, BASIC SYS 4608, raster gradient bars, centered logo text, SID arpeggio,
and a bottom scroller.

Use AUDIT.md for the original/corrected hash relationship and
shasum -a 256 -c SHA256SUMS.txt for integrity verification.
